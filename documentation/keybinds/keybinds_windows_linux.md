# Keybinds (Windows/Linux)

> You will need to have the default keybind configuration in order for these to apply.

- Ctrl + N - New file 
- Ctrl + O - Open file 
- Ctrl + S - Save file 
- Alt + S - Save as file 
- Alt + D - Discard file 

- Ctrl + C - Copy selected text 
- Ctrl + X - Copy selected text and remove it 
- Ctrl + V - Pastes copied text 
- Ctrl + A - Select all text in document 
- Ctrl + F - Find text in docment
- Ctrl + R - Replace old text with new text in document

- Ctrl + G - Open pyText's source code

- Ctrl + L - Open pyText settings
- Alt + W - Restart pyText
- Ctrl + W - Close pyText
